# Lista de Exercícios 01 - Estudando as estruturas básicas

Este repositório contém exercícios de programação em JavaScript da Turma 2 - do curso Dev. Full Stack Jr. (+praTi & Codifica).

## Para configurar e executar os exercícios localmente

1. **Pré-requisitos**  
   - [Node.js](https://nodejs.org/) instalado na máquina.

2. **Clone o repositório**
   ```bash
   git clone https://github.com/<seu-usuario>/<nome-do-repositorio>.git
   cd <nome-do-repositorio>
   ```

3. **Instale as dependências**
   ```bash
   npm install prompt-sync
   ```

4. **Execute o exercício desejado**
   ```bash
   node exercicio-XX.js
   ```
   Substitua `exercicio-XX.js` pelo nome do arquivo do exercício que deseja executar.

5. **Siga as instruções no terminal**  
   Cada exercício solicitará as informações necessárias e exibirá o resultado no console.
